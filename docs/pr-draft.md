# Draft: Align mobile GPUI types and make native iOS rendering work

Align gpui/gpui_wgpu with Ely/patch-map's Zed `1a28cff4b409169bac058bca40dfbfeb7621d19b` and crates.io wgpu `29.0.4`. Adapt platform, dispatcher, atlas and display APIs; match the example's reqwest source to avoid duplicate Client types. Core gpui-mobile stays independent of Ely, while the app-layer example supplies Ely assets. Application lockfiles preserve the tested libc resolution and TLS certificate validation remains enabled.

Fix two causes of a linked iOS app opening to a black screen: provide wgpu's Metal display handle and retain `run_embedded()`'s application handle while UIKit owns the run loop. Propagate renderer failures and provide a POSIX native simulator build path. The integrated scope also includes raw touch/pinch/lifecycle/inset contracts, asynchronous GPS, and opt-in BLE scan/connect/discover/read/write/notify/disconnect/reconnect with Android Java packaging.

Validation: the GPUI showcase compiled, linked, installed and visibly rendered on iPhone 17 Pro / iOS 26.3. The latest iOS Rc/Weak backend and Ely app also compiled and linked (7.33s), launched as PID 20634, and emitted `ELY_ADAPTER_SELFCHECK PASS`, including the cross-boundary-contact regression. All 13 real-GPUI simulator event/ownership/text/FIFO tests passed. Android root and example checks passed with BLE; the latest shared source compiled and linked as an ARM64 cdylib (26.07s). The BLE-enabled debug APK assembled successfully (1m02s), its signature verified, and its packaged native-library hash matches that cdylib. Dependency trees show one GPUI revision and one wgpu. See the compatibility matrix for artifact hashes and source identity.

Android execution, real GPS/BLE radio behavior, full surface recovery and FPS are not verified. No Android targets were connected. Actual click/drag/pinch and keyboard interaction were not performed because the Mac was locked. System-power sleep/wake is unsupported; Android idle inhibition explicitly errors. Some simulator emoji glyphs are missing. See [compatibility](compatibility.md), [mobile events](mobile-events.md), [location](location-service-integration.md), and [BLE](ble-integration.md) for evidence and platform constraints.
